# Clio providers

Own packages/adapters and assigned collector integration within scoped instructions. GitHub-first is proposed, not yet an accepted provider contract. Before collection, define service/environment mapping and evidence establishing production exposure, commit linkage, failure/rework classification, and recovery. Workflow success alone does not establish production effectiveness. Preserve namespaced identities, source revisions, observed times, canonical rollout grouping, and per-service coverage. Delivery order is not revision order; unknown revisions/conflicts require explicit reconciliation. Replayed or late arrivals must not mutate prior cutoff snapshots. Backfill and incremental sync share idempotent storage/checkpoints; collection gaps, rate limits, incomplete history, and revoked access remain visible. Test pagination, duplicates, partial failure, late evidence, and recovery from interrupted sync using fictional fixtures/mocks. Never fetch private repositories without assigned credentials and scope.
