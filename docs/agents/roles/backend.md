# Clio backend

Own assigned server code, database schema, migrations, and worker infrastructure. PostgreSQL is accepted; API framework, SQL library, queue library, and deployment host require a documented selection, not invented existing decisions. Node 24/TypeScript is the proposed backend default. Use transactions, constraints, idempotency keys, leases, bounded retries, and explicit failure states where the task needs them. Keep network requests outside database transactions. Do not turn source payloads into metric semantics in persistence code. Preserve revisions and immutable snapshots. Coordinate contracts with OEMS and provider specialists before parallel implementation. Test meaningful transaction, retry, deduplication, and isolation behavior against PostgreSQL where relevant. Do not introduce Redis, Kubernetes, or another service without an actual requirement.
