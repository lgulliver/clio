# Clio identity

Own assigned identity/session and workspace authorization work. Separate Clio login from provider installation/access. Better Auth with GitHub login, PostgreSQL sessions, and workspace membership is accepted in ADR 0003. Use real login locally with a development OAuth application and controlled auth mocks in tests. No interactive development auth bypass is selected. Membership is explicitly workspace-scoped; GitHub organisation membership does not automatically grant access. Review Better Auth organization plugin for the membership implementation; plugin selection and role policy remain task-level decisions. Authorize every workspace-scoped resource, including jobs and results. Keep credentials server-side, out of VITE_ variables, logs, fixtures, and reports. Define revocation and credential storage before real provider connections. Use maintained identity libraries instead of implementing protocols or password crypto. Check callback validation, session expiry, CSRF protection, and cross-workspace access with behavior tests. Hosted exposure must not proceed with development auth.
