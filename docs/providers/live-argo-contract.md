# Live Argo contract

Implementation contract for the approved [design](../superpowers/specs/2026-10-10-argo-ingestion-design.md). API and browser use these names exactly. This contract does not establish transport completeness.

## Native notification

Strict JSON envelope (all keys required, nullable native fields allowed):

```ts
interface NativeArgoNotification {
  contract: 'clio.argocd.notification.v1';
  application: {
    uid: string; name: string; namespace: string;
    project: string;
    destination: { server: string | null; name: string | null; namespace: string };
    repoURL: string | null;
    hasSources: boolean; hasSourceHydrator: boolean;
  };
  operation: {
    phase: string | null; startedAt: string | null; finishedAt: string | null;
    retryCount: number;
    info: { name: string; value: string }[];
    initiatedBy: { username: string | null; automated: boolean };
    revision: string | null; revisions: string[];
  };
  health: { status: string | null; lastTransitionTime: string | null };
}
interface ArgoScope {
  sourceId: string; workspaceId: string; serviceId: string;
  instance: string; applicationUid: string; applicationName: string;
  applicationNamespace: string; project: string;
  destinationClusterId: string; destinationServer: string | null;
  destinationName: string | null; destinationNamespace: string;
  configurationRepositoryId: string; repoURL: string; environment: string;
}
```

Provider package exports `parseArgoNotification(input: unknown, scope: ArgoScope, observedAt: string): ArgoNotification`. It authenticates no credentials: API owns that prerequisite. Shape or scope failure throws redacted `AdapterError`. Unsupported scope-valid native events return `kind:'gap'`. Supported events return `kind:'operation'`. Both carry `digest:string` (canonical SHA-256), `startedAt:string|null`, `canonicalJson:string`; operation adds `operationId:string`, `operationMetadataDigest:string`, `notificationRevision:string`, `phase:string`, `health:string`, `evidence:EvidenceBatch`. Gap adds `reason:ArgoGapReason`. Evidence uses existing normalized contract; exposure false and application provenance null. Export types from adapter index.

Gap reasons: `unmarked_operation`, `non_terminal`, `missing_sync_result`, `missing_health_timestamp`, `multi_source`, `source_hydrator`, `future_timestamp`, `invalid_operation_info`, `observation_horizon`, `status_combination_repeated`, `status_combination_limit`, `connection_interruption`. Last four may be generated by storage. Exact replay precedes new-arrival temporal checks: API first computes canonical replay identity through `argoNotificationDigest(input: unknown, scope: ArgoScope): string`, which validates shape/scope but not age. Timestamp validity remains strict. Never return raw/native fields to browser.

## Private operator configuration

`ARGO_INGESTION_GRANTS_FILE` contains a JSON array of ArgoScope fields plus `tokenFile:string`, no other fields. Token file contains exactly 64 lower-case hex digits (32 random bytes), optional terminal newline. Config loader returns immutable `ArgoConfig { grants: readonly ArgoGrant[] }`, `ArgoGrant extends ArgoScope { tokenDigest:string; fingerprint:string }`. Fingerprint includes full scope and tokenDigest; paths never retained. Export `readArgoConfig(env:NodeJS.ProcessEnv):Promise<ArgoConfig|null>` from API feature config. Maximum 100 grants, unique source and application binding and token digest. Owner-only files outside Git with symlink rejection. Missing environment variable disables; bad configuration throws `Invalid Argo ingestion configuration`.

## Browser API

Base `/api/workspaces/:workspaceId/services/:serviceId`:

- GET `/argo-connection` returns `{configured:boolean, sources:ArgoSource[], connection:ArgoConnection|null}`. Sources are granted sources for this exact workspace/service only. `configured` means matching grant available. Sources expose only `{sourceId, applicationName, applicationNamespace, instance, environment, enrichmentProducers?:EnrichmentProducer[]}`. Producer labels contain no credentials or private fingerprints.
- POST `/argo-connection`: `{expectedRevision:number|null, sourceId:string, applicationOperationsBelongToService:true, exposurePolicyReference:string|null, enrichmentProducerIds?:string[]}` returns `{connection:ArgoConnection}`.
- POST `/argo-connection/disconnect`: `{expectedRevision:number}` returns `{connection:ArgoConnection}`.
- POST `/argo-collection-runs`: `{connectionRevision:number, requestId:string, window:{start:string,end:string}}` returns 202 `{run:ArgoRun}`.
- GET `/argo-collection-runs`: `{runs:ArgoRun[]}` latest 25.
- GET `/argo-collection-runs/:runId`: `{run:ArgoRun}`.

```ts
interface EnrichmentProducer {
  producerId:string; capability:'consumer_exposure'|'application_provenance'; policyReference:string;
}
interface ArgoConnection {
  workspaceId:string; serviceId:string; mode:'live'; provider:'argocd';
  revision:number; active:boolean; sourceId:string;
  applicationName:string; applicationNamespace:string; instance:string;
  productionEnvironment:string; exposurePolicyReference:string|null;
  applicationOperationsBelongToService:true; observedAt:string;
  enrichmentProducers?:EnrichmentProducer[];
}
interface ArgoResult {
  workspaceId:string; serviceId:string; mode:'live'; provider:'argocd';
  connectionRevision:number; oemsRevision:string;
  window:{start:string;end:string;timezone:'UTC';calendarDays:number};
  evidenceCutoff:string; transportComplete:false;
  deploymentCount:number; qualifyingCount:number; unknownCount:number;
  retainedReceiptCount:number; retainedEvidenceCount:number; recordedGapCount:number;
  gapReasons:Record<string,number>;
  rejectionCount:number; scopeDriftCount:number;
  observationPeriod:{start:string|null;end:string};
  coverage:{collectionComplete:false;deploymentHistoryComplete:false;recoveryEvidenceComplete:false};
  deploymentFrequency:{count:number;status:'provisional';deploymentsPerDay:null;qualityReasons:string[]};
  changeFailureRate:null; failedDeploymentRecoveryTime:null;
  enrichmentSummary?:{retainedReceiptCount:number;consumerExposureCount:number;applicationProvenanceCount:number;policies:EnrichmentProducer[]};
}
interface ArgoRun {
  id:string;workspaceId:string;serviceId:string;mode:'live';provider:'argocd';
  connectionRevision:number;status:'pending'|'running'|'succeeded'|'failed';
  attempts:number;createdAt:string;updatedAt:string;completedAt:string|null;
  failureCode:'argo_processing_failed'|'argo_connection_revoked'|null;
  result:ArgoResult|null;
}
```

Result counts describe all eligible retained dates at cutoff, not reporting-window completeness. Receipt/evidence/gap counts use the current fingerprint and exact scope; observation period and rejection/drift counters span the whole source lifetime across grant revisions. Each disconnect/reconnect boundary contributes one interruption gap, so a pair contributes two; policy-only active re-save adds none. Counter changes and receipt inserts serialize with cutoff capture so result never incorporates later changes. Connection stores private grant scope/fingerprint separately from public DTO. IDs UUID; timestamps UTC up to six fractional digits. Closed whole-day windows 1–90 days.

## Integration interfaces and ownership

Backend exports `registerArgoRoutes(routes, {pool, argo, actor})` and separate `registerArgoIngress(app,{pool,argo})`; browser actor signature matches GitHub routes. Ingress registers authentication in `onRequest` before JSON parser. Redaction/no-store applies independently. `createArgoWorker(pool, argo)` exposes `runOnce():Promise<boolean>` and uses 120-second database leases with maximum three attempts. No outbound provider network. Coordinator wires startup/identity/readiness and standalone worker entry.

Backend owns API feature `argo-collection`, migration `0006_argo_ingestion.sql`, and scoped tests. Provider owns adapter native parsing/tests and committed notification YAML in `infra/argocd/`; verifies actual pinned controller via explicitly scoped sandbox. Frontend owns `features/argo-collection/` and settings composition. Coordinator owns shared manifests, entrypoints, readiness, architecture/runbooks and integration. Shared files require explicit handoff.

## Independent enrichment

The native contract above remains strict: consumer exposure is false and application provenance absent in native evidence. Separately authenticated enrichment receipts can qualify exact retained rollouts or attach immutable artifact/source provenance at a database cutoff. Producer grants, wire shapes, replay/rotation rules and operator responsibilities are documented in [independent Argo evidence](argo-enrichment.md) and the [implementation contract](../superpowers/specs/2026-10-10-argo-enrichment-design.md). Source rate and lifetime storage budgets are shared across both ingress kinds, including enrichment lock rows; adding producers cannot multiply capacity.

Enrichment admission also reserves serialized snapshot headroom in the shared 8 MiB byte budget. This accounts for repeated evidence/policy references by their encoded byte lengths, independently of grant size. Artifact exposure reserves the maximum application-repository representation until an immutable digest mapping is known; an existing digest lock permits a smaller exact reservation. The 5000-row ceiling is an additional limit, not a promise that 5000 assertions fit. Exact replay consumes no new storage or headroom. Reservations are not refunded by rotation or later captures.
