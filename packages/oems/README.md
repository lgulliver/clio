# @clio/oems

Clio's integration boundary with the OEMS standard. The initial package exports pinned upstream provenance only. Schema loading, snapshot validation and result handling will be added when the first adapter is implemented.

Normative definitions stay in lgulliver/oems. Do not recreate them here or treat this package's metadata as validation. Any future schema copies must retain their Apache 2.0 licence and provenance, be pinned to an exact commit and be updated deliberately.
