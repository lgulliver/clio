`resources.json` is generated by the sibling producer CLI. Argo synchronizes this directory at an explicitly selected full configuration commit. The HTML artifact comes from application source commit `de2295aa3bb078edea7af7c102f55f186d822ca5` in `github:lgulliver/clio`, path `infra/argocd/evidence-demo/app/index.html`.

Its exact byte digest is `sha256:caec442a9b61d0d572a24cc621655878d68e72f0c7024f5896e6de73784c612e`. This is not the NGINX image digest. The immutable ConfigMap embeds those bytes as base64; the Deployment mounts them read-only. The separate pinned NGINX image is `docker.io/library/nginx:1.29.3-alpine@sha256:b3c656d55d7ad751196f21b7fd2e8d4da9cb430e32f646adcf92441b72f82b14`.

Rebuild only from that committed application SHA to reproduce this sample. A new application artifact needs regenerated resources, a new configuration commit and new independent build evidence. Keep private grants, assertions and observation receipts outside Git.
