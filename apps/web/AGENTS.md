# Web application instructions

Apply the root AGENTS.md first.

- This is a browser React SPA built by Vite, with file-based TanStack Router routes and TanStack Query for server state.
- Add pages to src/routes. Generated routeTree.gen.ts must be regenerated by Vite and committed, never manually edited. Keep route modules thin; feature UI/data code belongs in src/features/<feature> when a feature exists.
- Use typed workspace imports. Query caches are created per app instance, not as shared request-global state.
- Do not put access tokens, provider SDK credentials, database access or source collection in this package. Any VITE_ setting is public.
- Use Tailwind utilities and shared design tokens. Respect reduced motion, keyboard navigation, screen-reader labels and visible focus.
- Test user-facing navigation, query behaviour and evidence states with Vitest/Testing Library. Do not fetch live providers in tests or label synthetic records as real data.
- Development is pnpm dev from the root; validation is pnpm check. Production hosting must route non-asset URLs to index.html for SPA navigation.
